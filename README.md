# 蛋糕对决 (Cake Duel)

在线双人版「蛋糕对决」：像骗子酒馆一样，牌面朝下出牌、可以撒谎声明牌名，对方可以放行或质疑，先赢下 3 局者获胜。

> 游戏与玩法来自 **I_Nori** 的原版「蛋糕对决」（B 站视频：[BV1h8uq6SECj](https://www.bilibili.com/video/BV1h8uq6SECj)）。
> 本项目为独立复刻，改为人人在线对战：主界面可创建房间、随机匹配，无需本地 AI 即可与好友或陌生人对决。

## 功能特性

- **人人在线对战**：创建私有房间（房间码邀请好友）或随机匹配陌生人
- **完整卡组**：基础卡 29 张 + 特殊卡 11 张（共 40 张），特殊效果全部实现
- **断线重连**：掉线后保留席位 45 秒、对局暂停，刷新/重连自动恢复
- **防挂机倒计时**：每回合限时，超时自动过牌
- **局内聊天**：右下角实时对话，未读角标
- **聊天历史**：新房间自动清空；观战者可见历史，回放附带完整聊天记录
- **质疑翻牌动画**：先翻牌、再判定本局结果，节奏分明
- **观战席**：房间满员后输入房间码可“观战”；未开局时自动等待，开局即进入观战（只公开翻牌信息，不显示手牌）
- **对局回放**：每局结束自动保存（最多 10 场），回放可查看双方手牌与真实出牌、聊天记录
- **管理员后台**：访问 `/admin` 会生成一分钟有效密码，可查看在线用户/房间/双方手牌/聊天，并强制解散房间
- **响应式布局**：桌面与移动端（横屏）均可游玩，移动端竖屏自动提示横屏
- **Redis 可选**：随机匹配、在线会话、房间实时记录（含手牌/聊天）走 Redis，连不上自动降级内存；对局结束自动移除房间记录

## 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3 + TypeScript + Vite |
| 后端 | Go + Gorilla WebSocket |
| 存储 | 无需数据库；房间与对局全部在内存中（Redis 可选） |

## 快速开始

### 1. 启动后端

```bash
cd backend
go build -o cakeduel-server.exe ./cmd/server
./cakeduel-server.exe
```

默认监听 `:8080`，并托管前端静态资源（`app/dist`）。配置见 `backend/configs/config.yaml`。

### 2. 构建前端

```bash
cd app
npm install
npm run build
```

构建产物输出到 `app/dist`，后端启动后直接访问 `http://localhost:8080` 即可。

### 3. 前端开发模式（可选）

```bash
cd app
npm run dev
```

- 前端通过 `/ws` 直连后端，**不依赖任何代理**
- 开发模式自动连接 `ws://127.0.0.1:8080`；生产环境自动同源（后端托管 `dist`）
- 后端换地址/端口时，修改 `app/src/config.ts` 的 `wsUrl`

### 配置说明（`backend/configs/config.yaml`）

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `gateway.port` | 服务端口 | `8080` |
| `game.rounds-to-win` | 先赢几局获胜 | `3` |
| `game.special-cards-to-add` | 加入牌堆的特殊卡数量（调小则每局随机抽部分） | `11` |
| `game.turn-timeout-seconds` | 每回合倒计时，超时自动过牌 | `60` |
| `game.disconnect-grace-seconds` | 断线重连宽容期 | `45` |
| `redis.*` | Redis 连接（可选，连不上自动降级） | `localhost:6379` |

## 玩法规则

### 目标

先赢下 **3 局**者获胜。每局开始时，双方共有 7 个蛋糕：**进攻方 3 个，防守方 4 个**，双方各 4 张手牌（每轮攻防后补满）。

### 进攻

进攻方牌面朝下出牌，再**声明一个牌名**。可以说谎——打出的牌不必与声明的牌名一致。

### 防守

防守方受到进攻时，可以：

- 牌面朝下打出**克制牌**防守（同样可以撒谎），挡住部分或全部攻击；
- **放行**（接受进攻）：每张未被挡住的牌都会按声明牌的效果抢走蛋糕；
- **质疑**：翻开进攻方的牌，对质声明。

进攻方也可以用同样的方式质疑防守方的声明。

### 质疑

质疑会翻开被质疑的牌：

- 有任意一张牌与声明不符 → **说谎者输掉本局**；
- 全部相符 → **质疑者输掉本局**。

### 一局如何结束

满足以下任一条件本局结束：

- 有人失去所有蛋糕；
- 质疑分出结果；
- 双方连续过牌（过牌结束时蛋糕更多的一方获胜）。

### 卡组（共 40 张）

**基础卡 29 张**

| 卡牌 | 数量 | 类型 | 效果 |
| --- | --- | --- | --- |
| 士兵 | 7 | 剑牌 | 抢走 1 个蛋糕 |
| 弓箭手 | 6 | 剑牌 | 抢走 1 个蛋糕 |
| 法师 | 5 | 火焰牌 | 抢走 2 个蛋糕 |
| 盾卫 | 6 | 盾牌 | 挡住一个来抢蛋糕的剑牌 |
| 科学家 | 4 | 盾牌 | 挡住一个来抢蛋糕的火焰牌 |
| 狼爵士 | 1 | 羊牌 | 不能声明狼爵士；撒谎时可混进打出的牌里，一旦被质疑就必输，回合结束时翻开嘲讽对手 |

**特殊卡 11 张**

| 卡牌 | 数量 | 类型 | 效果 |
| --- | --- | --- | --- |
| 刺客 | 1 | 剑牌 | 抢走 5 个蛋糕 |
| 斥候 | 1 | 剑牌 | 抢 1 个蛋糕，然后**再行动一回合** |
| 召唤师 | 1 | 火焰牌 | 指定一张卡牌名称，查看对手手牌，每有一张同名牌就抢 2 块蛋糕 |
| 军需官 | 1 | 星星牌 | 本局剩余时间手牌上限 +1 |
| 神谕师 | 1 | 星星牌 | 查看对手手牌，然后**再行动一回合** |
| 牧师 | 2 | 盾牌 | 挡住一张剑牌/火焰牌/星星牌并收入你的手牌，取消其效果 |
| 天使 | 1 | 盾牌 | 挡住所有的牌并取消全部效果，然后对手**再行动一回合** |
| 咩格拉底 | 1 | 羊牌 | 咩格拉底教授和狼爵士在本回合变为科学家 |
| 特工U | 1 | 羊牌 | 变成对手手牌中的任意一张牌 |
| 绵顿 | 1 | 羊牌 | 变成你上回合打出的那张剑牌/火焰牌/星星牌的副本 |

> 特殊卡每局全部加入牌堆；如需每局随机抽部分特殊卡，可调小 `config.yaml` 的 `special-cards-to-add`。

### 对战体验

- 主界面可创建私有房间（生成房间码，好友输入即可加入）或随机匹配；随机匹配有匹配中界面（动画 + 等待计时，可取消）
- 每回合倒计时（`config.yaml` 的 `turn-timeout-seconds` 可调），超时自动过牌，防止挂机
- 断线重连：掉线后保留席位 45 秒（`disconnect-grace-seconds` 可调），**对局暂停**等待重连；同浏览器刷新/重连后自动恢复对局
- 查看手牌类效果（神谕师/召唤师/特工U）只有查看者能看到被查看的手牌，被查看方不会看到自己的牌被展示
- 右下角可展开局内对话

## Redis（可选）

随机匹配队列和在线会话标记走 Redis（可用时），Redis 挂了自动降级为内存队列。
对局中的房间快照（房间码/双方手牌/观战人数/聊天记录等）也会写入 Redis，对局结束即删除。
单实例部署 Redis 不是必需；多实例横向扩展时匹配队列天然共享。

## 管理员后台（可选）

- 浏览器访问 `http://服务器地址:8080/admin`
- 打开页面后服务端在 Redis 生成一个 **1 分钟有效**的一次性密码（键 `cakeduel:admin:password`，页面不回显）
- 管理员用 Redis 客户端读取密码并输入，校验成功后密码即被删除并发放 30 分钟后台令牌
- 进入后可查看在线用户、房间状态、双方手牌、观战者与聊天记录
- 支持“强制解散房间”，所有玩家与观战者会被移出房间

```bash
# 示例: 读取当前一次性访问密码
redis-cli GET cakeduel:admin:password
```
